# Third-party notices — OwnRAG console (`web/`)

This file records the third-party software the OwnRAG console depends on, with the licence
each package declares in its own `package.json`, read from the installed tree. It exists
because Apache-2.0 §4 and the console's MIT/ISC dependencies all require that copyright
notices be preserved in a redistribution — and because "do not remove attribution" is a
position, not a checkbox.

Generated by reading `web/node_modules/<pkg>/package.json` for every entry in
`web/package.json`.

## Attribution kept in the product

- **React Flow / `@xyflow/react`** renders its attribution badge in the corner of the agent
  canvas, and OwnRAG leaves it visible. The library's MIT licence permits hiding it
  (`proOptions={{ hideAttribution: true }}`); the console deliberately does not, because a
  product that argues for attribution should not be the one removing it.
- Fonts are loaded from Google Fonts (Geist, Geist Mono, Inter, JetBrains Mono). Geist and
  Inter are licensed under the SIL Open Font License 1.1; JetBrains Mono under the OFL 1.1;
  Geist Mono under the OFL 1.1. The console's stacks fall back to the system UI font if the
  CDN is unreachable.
